\huge\textbf{\textit{Stuck on a problem in applied mathematics?}}\\

\Large\textbf{\textit{Have you tried ...}}\\

\begin{itemize}

\item[$+0$~~] adding zero creatively

\item[$\times1$~~] multiplying by one creatively

\item[$\sim$~~] scaling arguments

\item[$!$~~] spotting a symmetry

\item[$\circlearrowleft$~~] rotating the axes

\item[$(\xi,\eta)$~~] changing coordinates

\item[$\frac{\text{D}\textbf{u}}{\text{D}t}$] switching between Eulerian and Lagrangian coordinates

\item[$i$~~] using complex variables 

\item[$\varepsilon$~~] perturbing about equilibrium

\item[$d=1$~~] studying the 1D case

\item[\textregistered~~] reverse-engineering a solution 

\item[$x_i\textbf{e}_i$~~] expanding in a basis

\item[$\lim_{x}$~~] taking limits to 0 or $\infty$ 

\item[$(\textbf{k},\omega)$~~]  going to Fourier space

\item[$\sum$~~] converting an integral to a sum

\item[$\int$~~] converting a sum to an integral

\item[$\Lambda$~~] cutting off the integral

\item[$\Delta x$~~] discretizing the problem

\item[$\nabla$~~] using a vector calculus identity

\item[$\delta$~~] using a property of the Dirac delta function

\item[$v$~~] multiplying by an arbitrary test function 

\item[$\Omega$~~] integrating over an arbitrary test domain

\item[$\lessgtr$~~] finding upper or lower bounds

\item[$+\dots$~~] neglecting small terms

\item[$\checkmark$~~] looking for self-consistency or contradiction

\item[$C$~~] identifying conserved or invariant quantities

\item[] thinking about the physics (e.g. balance of forces, consevation of mass, momentum or energy)
	
\end{itemize}
